# Ferramentas

JUCESP: NIRE a partir de Sócio expõe 1 ferramenta (todas somente leitura).

### 1. `jucesp_nire_socio_consultar`
**Input**: `login_cpf` (opcional), `login_senha` (opcional), `pkcs12_cert` (opcional), `pkcs12_pass` (opcional), `socio_nome` (opcional), `socio_cpf` (opcional), `socio_cnpj` (opcional), `inclui_inativas` (opcional)

Encontra empresas na JUCESP a partir de um sócio (nome, CPF ou CNPJ), retornando o NIRE de cada participação.

## Prompts de exemplo

```
Quais empresas esse CPF tem registro na JUCESP?
```
